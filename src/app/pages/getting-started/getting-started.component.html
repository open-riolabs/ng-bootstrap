Installation

Requires Angular 17.2+ and Bootstrap 5.3. The schematic does the wiring for you.

Option 1 — ng add recommended

One command installs the dependencies, registers the styles, wires the providers and scaffolds a starter component.

  • Installs bootstrap, bootstrap-icons, @open-rlb/date-tz, @ngx-translate/core and @angular/cdk.
  • Registers the Bootstrap and Bootstrap Icons stylesheets in angular.json.
  • Adds provideRlbBootstrap() to your application providers.
  • Scaffolds a starter component you can render to verify the setup.
  • Copies the bundled Claude skills into .claude/skills/ (date-tz and component guides).

Theming & dark mode

Bootstrap 5.3 ships a full dark mode behind the data-bs-theme attribute, and provideRlbTheme() drives it from signals: it follows the operating system when asked to, remembers the choice, and never touches the DOM on the server. It is deliberately not part of provideRlbBootstrap() — an app that never asked for a theme should not suddenly find data-bs-theme written on its <html>.

Icons

Every icon the library draws is named by what it means rather than by which glyph it is, and resolved through RLB_ICONS. The default set is bootstrap-icons; point some or all of them somewhere else and the whole library follows.

Defaults

Labels, page sizes and the date zone can be set once instead of on every element. An element that says something still wins; anything left out keeps the built-in English.

Translations

The library depends on no translation package. Text you can pass in is an input with an English default; the one component that takes keys rather than text (rlb-form-fields, whose field definitions are data) resolves them through RLB_TRANSLATION_SERVICE, returning the key unchanged when nothing is registered. Bridging @ngx-translate/core to it is one provider.
